## 关键测量

| 场景 | 结果 |
|---|---|
| 球形双向绕行，各 20 秒 | 各约 3.29 圈，2400/2400 帧接地 |
| 胶囊双向绕行，各 20 秒 | 各约 2.68 圈；正向 2397/2400、反向 2400/2400 帧接地 |
| 胶囊接触间隙 | 最长接地丢失 2 物理帧；最大间隙 0.099 世界像素 |
| 球形、胶囊各 8 点跳跃 | 全部离地并落回原星球 |
| 球→胶囊、胶囊→球 | 均着陆，来源各切换一次，落地后可移动 |
| 连续球→胶囊→球 | 无中途重置或传送，成功 |
| 高速运动 | 切向发射与提高地面加速度/最高速度两种方式均可自然离地 |
| 无重力区域 | 速度保持不变，一秒位移符合惯性运动 |
| 输入 | R 实际事件重载场景；鼠标按下/移动/释放经过 viewport 输入派发完成发射 |
| 瞄准 | 地面允许、空中拒绝；位置速度冻结；上限、取消、小拖拽死区通过 |

绕行和旅行逐物理帧检查了明显穿透和非有限速度。该检查使用默认吸引形状与实体一致的前提；分离吸引形状后不能用吸引边界距离替代实体穿透检测。

## 不代表已验收的部分

测试覆盖默认地图和选定轨迹，未穷举任意参数、所有发射角度和边界等距停留。固定步频测试不是不同 GPU/真实负载的性能测试。

自动输入使用游戏画布坐标，真实鼠标在缩放窗口中的舒适度和拖拽手感仍需用户试玩。局部左右理解、跳跃手感、着陆体验和旅行难度均未宣称体验验收通过。
